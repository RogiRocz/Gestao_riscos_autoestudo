# front-gestao-riscos-vue3

This is a Vue 3 project using Vite, Pinia, Vuetify 3, Vue Router, TypeScript, ESLint, Prettier, and Axios.

## Project Setup

```sh
npm install
```

### Compile and Hot-Reload for Development

```sh
npm run dev
```

### Type-Check, Compile and Minify for Production

```sh
npm run build
```

### Lint with [ESLint](https://eslint.org/)

```sh
npm run lint
```
